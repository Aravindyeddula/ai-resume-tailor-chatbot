This demo document is used by make sanity.

Main contribution:
The project implements a deterministic command-line RAG assistant that ingests markdown or text files, retrieves relevant chunks using hybrid lexical search, and returns grounded answers with structured citations.

Limitations:
The baseline uses lexical retrieval, so deep semantic matches can still be weaker than embedding systems. Optional LLM answer mode requires OPENAI_API_KEY and falls back to deterministic synthesis when unavailable.

Numeric detail:
The chunking strategy uses a 700 character chunk size with 120 character overlap for long paragraphs.
